# أمين للآيفون

دفتر عربي للمصروفات والدخل والديون. يتطلب iOS 17 أو أحدث. يبدأ بسجل فارغ، ويعمل محليًا حتى عند انقطاع الإنترنت.

## الاستخدام

- من الرئيسية، اختر «إضافة حركة» أو «مساعد أمين». يمكنك إملاء عبارة مثل «دفعت ٣٥ ريال للقهوة» باستخدام لوحة مفاتيح الآيفون. راجع الاقتراح ثم احفظه.
- يعرض صافي الشهر مجموع الدخل مطروحًا منه المصروفات. يعرض قسم الديون المبالغ المستحقة لك وعليك عبر جميع الأشهر. تسجيل الدين أو دفع قسط منه يغير دفتر الديون فقط.
- من الحركات والديون يمكنك البحث والتصفية والتعديل والحذف. افتح دينًا لتسجيل دفعة والاطلاع على سجل السداد. يرفض التطبيق أي دفعة تتجاوز المتبقي.
- من الإعدادات يمكنك ضبط ميزانية شهرية تتكرر كل شهر، وكتم النغمات، وتصدير نسخة JSON إلى الملفات أو استعادتها. النسخة المصدرة قابلة للقراءة.
- يدعم الخط الديناميكي وVoiceOver، وتُقرأ فئات الرسم البياني ومبالغها ونسبها كنص. يعمل مصنّف الفئات على الجهاز ويستخدم تشابه كلمات العمليات السابقة مع العبارة الجديدة. حفظ الاقتراح يتطلب تأكيدك.

## البناء

افتح `Ameen.xcodeproj` في Xcode 16 أو أحدث، واختر مخطط Ameen. للتشغيل على آيفون حقيقي حدّد فريق التطوير في Signing & Capabilities وغيّر معرّف الحزمة إذا تطلب حسابك ذلك. للبناء من جذر المستودع:

```sh
xcodebuild -project Ameen/Ameen.xcodeproj -scheme Ameen -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
swiftc Ameen/App/Ledger.swift Ameen/App/Assistant.swift Ameen/Tests/main.swift -o /tmp/ameen-tests
/tmp/ameen-tests
```

يبني مسار GitHub Actions تطبيق الآيفون ويحزم ملف IPA غير موقّع. يتطلب تثبيت التطبيق على جهاز فعلي توقيعًا متوافقًا.

## مستشار أمين في الإصدار 2.0

عند فتح التطبيق تظهر علامة الدفتر والنجمة، ويقودك زر «مستشار أمين» في الرئيسية أو تبويب «المستشار» إلى ثلاث طرق للسؤال.

- **دفتري** يحسب المصروفات حسب الفترة والفئة، ويقارن الشهور، ويحسب ميزانية اليوم والديون باسم الشخص وأقرب الاستحقاقات. تدخل المبلغ الشهري في محاكي السداد لتعرف عدد الدفعات وحجم الأخيرة. عند توافر نموذج Apple على الجهاز ودعمه للعربية يمكنه شرح أسئلة مفتوحة بالاستناد إلى الملخص.
- **مصادر عامة** يجلب آخر قيمة سنوية متاحة للتضخم أو البطالة أو نمو الناتج في السعودية من البنك الدولي، مع سنة البيان. للموضوعات الأخرى يجلب مقتطفات وروابط من ويكيبيديا العربية. يحتاج اتصالًا بالإنترنت.
- **نموذج سحابي** يرسل سؤالك مباشرة إلى OpenAI عبر Responses API باستخدام مفتاحك الشخصي. عند تفعيل البحث يطلب بحث الويب ومراجع قابلة للفتح. يرسل آخر ثلاث جولات سحابية بنفس اختيار مشاركة الملخص، ويحتفظ بالمحادثة في الذاكرة. يضيف إجماليات الشهر والديون فقط إذا فعّلت الخيار، ويمكنك معاينتها. تبقى أسماء أصحاب الديون وتفاصيل المعاملات في الدفتر ما لم تكتبها أنت في سؤالك. تخضع طلبات النموذج والبحث لتكلفة حساب API. المفتاح محفوظ في Keychain على هذا الجهاز ويمكن إزالته من شاشة إعداده.
- لا تغيّر الإجابات أرصدة الدفتر. لتسجيل حركة استخدم «مساعد أمين» وراجع الاقتراح قبل الحفظ.

للحصول على تكامل نموذج Apple، ابنِ باستخدام Xcode 26 أو أحدث. تبقى الوظائف الأخرى متاحة على iOS 17 أو أحدث.
