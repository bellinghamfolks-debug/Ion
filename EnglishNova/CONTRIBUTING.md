# إرشادات إضافة المحتوى

1. استخدم معرفات فريدة وثابتة للدروس والتمارين والكلمات.
2. اكتب هدفًا تعليميًا واحدًا قابلًا للقياس لكل درس.
3. اجعل السؤال مباشرًا، وحدد إجابة نموذجية وإجابات مقبولة عند الحاجة.
4. أضف تفسيرًا عربيًا يشرح السبب، لا يكرر الإجابة فقط.
5. اختبر ترتيب VoiceOver، ولا تجعل السحب الوسيلة الوحيدة للتفاعل.
6. ضع وصفًا نصيًا دقيقًا لأي صورة أو مخطط.
7. شغّل `python3 Scripts/validate_content.py` قبل الدمج.
