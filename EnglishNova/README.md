# EnglishNova 0.4.0

EnglishNova مشروع iOS حديث لتعلّم الإنجليزية من الصفر حتى المستوى المتقدم. بني بأسلوب Offline First، بحيث تعمل الدروس والمراجعة ومختبرات القراءة والاستماع والكتابة والقصص والتدريب الأساسي محليًا، ثم تضاف الخدمات الشبكية الاختيارية عند إعداد خادم HTTPS.

هذه نسخة موحدة تجمع الدفعات الأولى والثانية والثالثة والرابعة داخل المشروع والملفات نفسها. لا توجد حزمة إضافات منفصلة تحتاج إلى دمج يدوي.

## أبرز إمكانات النسخة

- SwiftUI مع MVVM ومستودعات وبنية حقن اعتماديات.
- iOS 17 أو أحدث.
- 152 درسًا و880 تمرينًا و456 مدخل مفردات.
- 120 درسًا كاملًا في A0 وA1.
- اختبار تحديد مستوى تكيفي من 12 إلى 24 سؤالًا.
- 24 نشاط قراءة، و24 نشاط استماع، و24 مهمة كتابة من A0 إلى C1.
- ستة مسارات: التأسيس، الطلاقة اليومية، IELTS، STEP، الإنجليزية المهنية، والقانون والحوكمة.
- خمسة أوضاع للدراسة: متوازن، اختبارات، محادثة، مهني، وهادئ.
- مراجعة تكيفية تقيس صعوبة البطاقة وثبات الذاكرة والانتكاسات واحتمال التذكر مع الزمن.
- حالات إتقان مستقلة لكل نشاط وتقارير أسبوعية قابلة للمشاركة نصيًا.
- تقييم كتابة محلي لمتطلبات المهمة والتنظيم والتنوع اللغوي والميكانيكا.
- ذاكرة تعليمية ودفتر أخطاء وتحليل نطق كلمة بكلمة.
- مدرب محادثة صوتي محلي مع خادم HTTPS اختياري.
- 12 سؤال IELTS Speaking، و24 سؤال STEP، و18 سؤال مقابلة عمل.
- 12 قصة متفرعة و12 سيناريو محادثة.
- قاموس شخصي مع مفضلة وتصنيفات وملاحظات.
- حزم صوتية وتحديث منهج اختياريان مع تحقق SHA-256.
- تذكيرات ونسخة احتياطية JSON بالمخطط الرابع.
- لا توجد مكتبات خارجية ولا مفاتيح API داخل المشروع.

## حدود التقييم المحلي

تحليل النطق يعتمد على تفريغ الكلام وتوقيته وثقة نظام التعرف، وليس تحليلًا مخبريًا مباشرًا للفونيمات. تقييم الكتابة مؤشر تعليمي محلي قائم على قواعد واضحة، وليس درجة رسمية في IELTS أو STEP.

## التشغيل

1. فك ضغط المشروع على جهاز Mac.
2. افتح `EnglishNova.xcodeproj` في Xcode.
3. اختر فريق التطوير من Signing & Capabilities.
4. اختر جهاز iPhone أو المحاكي.
5. اضغط Run.

## إعادة توليد المشروع اختياريًا

يوجد `project.yml` لاستخدام XcodeGen:

```bash
brew install xcodegen
xcodegen generate
open EnglishNova.xcodeproj
```

## الفحص المحلي

```bash
python3 Scripts/validate_content.py
python3 Scripts/validate_project.py
Scripts/validate_core_semantics.sh
```

الفحص البنيوي يراجع المنهج وعضوية الملفات ومسارات مجموعات Xcode وصياغة Swift. الفحص الدلالي يجمع ويشغّل نواة Foundation، ويختبر الترحيل والمراجعة التكيفية والإتقان ومختبرات المهارات والتقارير.

## الخصوصية

- لا يلزم حساب.
- بيانات التقدم والقاموس والذاكرة التعليمية محفوظة محليًا.
- لا يرسل التطبيق التسجيل الصوتي الخام إلى الخادم الاختياري ضمن العقد الحالي.
- قد تستخدم خدمة التعرف على الكلام معالجة النظام وفق إعدادات iOS وسياسات Apple.
- عند تفعيل المدرب المتصل، يرسل النص المفرغ وسياق الموقف والنتيجة المحلية فقط.
- النسخ الاحتياطية تنشأ محليًا ويحدد المستخدم وجهتها.
