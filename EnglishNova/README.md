# EnglishNova 2.0

## ما الجديد في 2.0

- أربعة تبويبات: اليوم، المسار، التدريب، أنا.
- «جلسة اليوم»: مراجعة ← الدرس التالي ← تدرّب على أخطائك ← تحدّث دقيقتين، مع حفظ ما أُنجز في اليوم.
- خريطة «المسار» لكل مستوى بحالات واضحة (مكتمل، التالي، لم يبدأ).
- مشغّل دروس جديد: «السؤال n من N»، جولة تصحيح للأخطاء لا تغيّر الدرجة، ملخص بكلمات الدرس، وحفظ الأخطاء لتعود في التدريب العلاجي.
- أربعة أنواع تمارين تُولَّد على الجهاز من مفردات الدرس دون تعديل ملف المنهج: التوصيل، صح/خطأ، استمع واكتب، الإملاء.
- إعداد أول تشغيل في نحو دقيقة: الهدف، المستوى، الوقت اليومي والتذكير، الاسم.
- VoiceOver: النقر المزدوج بإصبعين يعيد الصوت، وإيماءة الخروج تفتح تأكيد الخروج، وعناوين وإعلانات للنتيجة.
- محادثة صوتية بدون لمس، ومدرّب نطق بالتظليل (Shadowing) من جمل دروسك، واختيار أفضل صوت إنجليزي مثبّت.
- مدرّب كتابة بأنواع كتابة ومعايير تقييم أربعة ونسخة محسّنة تُقارن بالسابقة.
- «اشرح أي نص»: تصوير أو صورة أو لصق، مع قراءة النص على الجهاز.
- رصيد يومي لميزات الذكاء الاصطناعي على الخادم (`ENGLISHNOVA_AI_DAILY_UNITS_PER_USER`، `ENGLISHNOVA_AI_DAILY_UNITS_GLOBAL`) يُعرض في تبويب التدريب.
- اختبار IELTS تجريبي كامل (Listening وReading، 40 سؤالًا، وقت حقيقي، خيار وقت إضافي 25٪).
- لوحة المهارات الست وتقدير تقريبي لمستوى CEFR، وكلمة اليوم، وحماية السلسلة، وتذكيرات ذكية تُخطط على الجهاز.


EnglishNova تطبيق iOS لتعلّم الإنجليزية بأسلوب Offline First من المستوى التمهيدي حتى C1. الدروس والمراجعة والتدريب الأساسي تعمل محليًا، بينما الحساب والمزامنة وبعض خدمات الذكاء الاصطناعي تستخدم خادم EnglishNova عند توفر الإنترنت.

المشروع الحالي هو المصدر الموحد، ويتضمن تحديثات المنهج، مراجعة الدروس المجتازة، الحساب والمزامنة، Google Sign-In، اختبارات الجودة، والخادم المتكامل الموجود في مجلد `../server`.

## أبرز الإمكانات

- SwiftUI مع MVVM ومستودعات وحقن اعتماديات.
- iOS 17 أو أحدث.
- 232 درسًا، و5940 تمرينًا، و1424 مدخل مفردات من A0 إلى C1، مع تحسينات مستوى تضاف حتميًا عند تحميل المنهج.
- مسار IELTS Academic إلى Band 6.0 بخطة لا تقل عن 180 دقيقة يوميًا، وخارطة 36 أسبوعًا، وقياس جاهزية محافظ للمهارات الأربع.
- مراجعة كلمات تكيفية ومراجعة منفصلة للدروس المجتازة بجدولة متباعدة.
- اختبار تحديد مستوى، قراءة، استماع، كتابة، محادثة، نطق، قصص، IELTS، STEP، المقابلات، والمسارات المهنية والقانونية.
- حساب اختياري بالبريد وكلمة المرور أو Google مع مزامنة التقدم بين الأجهزة.
- خادم Node.js/PostgreSQL يتحقق من Google ID token قبل إصدار جلسة EnglishNova.
- دعم العربية والإنجليزية مع طبقة ترجمة داخلية وتدقيق آلي للنصوص.
- GoogleSignIn-iOS هو الاعتماد الخارجي الرئيسي لتسجيل الدخول.
- لا تُحفظ مفاتيح Google OAuth أو أسرار JWT داخل ملفات Swift أو المشروع.

## البناء

المصدر المرجعي للمشروع هو `project.yml`. أنشئ مشروع Xcode بواسطة:

```bash
brew install xcodegen
cd EnglishNova
xcodegen generate
open EnglishNova.xcodeproj
```

## Google Sign-In

`Info.plist` يستخدم إعدادات بناء بدل قيم ثابتة:

- `GOOGLE_IOS_CLIENT_ID`
- `GOOGLE_SERVER_CLIENT_ID`
- `GOOGLE_REVERSED_CLIENT_ID`

مهمة IPA الإنتاجية ترفض إنشاء نسخة ناقصة إذا لم تُضبط القيم. راجع `Docs/GOOGLE_SIGN_IN_SETUP.md` لإعداد Google Cloud وGitHub Actions وCodemagic وRailway.

## الفحص

```bash
python3 Scripts/audit_arabic_ui.py
python3 Scripts/validate_project.py
Scripts/validate_core_semantics.sh
```

GitHub Actions يشغّل تدقيق الواجهة، التحقق البنيوي، فحوص JavaScript، اختبارات iOS، والتحقق من وجود المنهج داخل التطبيق. كما ينشئ مصدرًا مضغوطًا مستقلًا لكل تشغيل، وتُنشأ IPA فقط عندما تكون قيم Google الإنتاجية مهيأة.

## الخصوصية والوصولية

- لا يلزم حساب لاستخدام التعلم المحلي.
- بيانات التقدم تحفظ محليًا، ولا تُرسل إلى الحساب إلا عند استخدام المزامنة.
- حذف الحساب يحذف الحساب والتقدم المتزامن من الخادم، ولا يمحو البيانات المحلية تلقائيًا.
- كل ميزة شبكية يجب أن تعرض خطأ مفهومًا وتبقي المسارات المحلية المتاحة قابلة للاستخدام.
- الواجهة مصممة لقارئات الشاشة ولا تعتمد المعلومة الضرورية على اللون وحده.
