# الأمان والخصوصية

## المفاتيح والأسرار

لا تضف مفاتيح API إلى Swift أو JSON أو إعدادات المشروع. استخدم خادمًا خلفيًا، أو ملف `Secrets.xcconfig` محليًا وغير مضمّن في Git. لا يوجد في النسخة المسلّمة مفتاح API أو مكتبة تحليلات أو تتبع إعلاني.

## الخادم

- يقبل عميل التطبيق عنوان HTTPS صالحًا فقط.
- يحدّ عميل JSON الاستجابة بعشرة ميغابايت، ويختصر رسالة الخطأ القادمة من الخادم.
- ينبغي للخادم تطبيق مصادقة قصيرة العمر، وتحديد معدل الطلبات، والتحقق من المدخلات.
- لا تسجل نصوص المستخدم أو بياناته التعليمية الحساسة دون موافقة وسياسة احتفاظ واضحة.

## تحديثات المحتوى

- رابط الحزمة يجب أن يستخدم HTTPS.
- الحد الأقصى للحزمة 15 ميغابايت.
- يتحقق التطبيق من SHA-256 قبل التثبيت.
- يفك التطبيق ترميز الحزمة كاملًا إلى `CourseCatalog` قبل اعتمادها.

## حزم الصوت

- روابط المقاطع يجب أن تستخدم HTTPS.
- الحد الأقصى للمقطع الواحد 100 ميغابايت.
- يمكن للخادم توفير SHA-256 لكل مقطع، ويتحقق التطبيق منه قبل الحفظ.
- تمنع طبقة التخزين أسماء الملفات التي تحاول الخروج من مجلد التطبيق.

## النسخ الاحتياطي

- الحد الأقصى للملف 25 ميغابايت.
- يقبل التطبيق إصداري المخطط 1 و2 فقط.
- تُنقّى القيم المستوردة مثل الهدف اليومي وسرعة النطق والوقت والنقاط.
- لا تتضمن النسخة التسجيلات الصوتية أو أسرار الخادم.

## الصوت والميكروفون

التعرف على الكلام يعمل محليًا أو عبر خدمات النظام بحسب الجهاز وإعداداته. لا يرفع EnglishNova التسجيل الصوتي إلى خادم التطبيق في هذه الدفعة. أي رفع مستقبلي يحتاج موافقة منفصلة وواضحة.
