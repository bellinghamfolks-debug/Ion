# iDiagnostics 2.0

إعادة بناء كاملة لتطبيق فحص عتاد iPhone باستخدام SwiftUI وواجهات Apple العامة فقط.

## مبادئ الاعتمادية

- لا تُختلق أي قيمة لا يتيحها iOS، مثل صحة البطارية أو عدد دوراتها.
- كل نتيجة تذكر مصدرها: قياس آلي، تأكيد المستخدم، أو كلاهما.
- تُحفظ الجلسة محليًا بعد كل نتيجة بكتابة ذرية، وتُعزل البيانات التالفة بدل تعطيل التشغيل.
- توقف الكاميرا والميكروفون والصوت والمستشعرات عند مغادرة شاشة الفحص.
- لا توجد تحليلات أو إعلانات أو خادم خلفي، ولا تُرفع النتائج أو التسجيلات.
- التقرير متاح نصيًا لقارئ الشاشة، وبصيغة PDF، وبصيغة JSON.

## حدود صريحة

التطبيق أداة فحص إرشادية، وليس Apple Diagnostics ولا بديلًا عن فحص مركز صيانة. بعض عناصر العتاد لا يتيح iOS اختبارها مباشرة، لذلك تُعرض كغير قابلة للفحص أو تحتاج تأكيد المستخدم.

## البناء والاختبار

```bash
cd iDiagnostics
xcodegen generate
xcodebuild test -project iDiagnostics.xcodeproj -scheme iDiagnostics -destination 'platform=iOS Simulator,name=<available device>' CODE_SIGNING_ALLOWED=NO
```

يتطلب المشروع iOS 16 أو أحدث وSwift 5.10. ينشئ XcodeGen المشروع من `project.yml`، وتشغّل GitHub Actions اختبارات الوحدة وبناء المحاكي على كل فرع تطوير.
